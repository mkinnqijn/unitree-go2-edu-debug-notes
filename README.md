# Unitree Go2 EDU｜环境配置与调试记录

这里整理的是 **Unitree Go2 EDU 四足机器人**的实际调试过程，供机器狗兴趣小组同学参考。

## 这个仓库是做什么的？

记录在 **Windows 11 + VMware + Ubuntu 20.04** 环境下，配置机器狗通信网络、使用 **Unitree SDK2 / SDK2 Python** 运行示例程序，以及排查连接问题时遇到的现象和解决办法。

这是一份根据实际操作整理的**经验记录**，不是宇树官方教程，也不是可适用于所有设备的一键配置脚本。

## 已记录的实测结果

- 通过 VMware 桥接网卡，使 Ubuntu 虚拟机与 Go2 EDU 的有线连接正常通信。
- 使用 Unitree SDK2 Python 的高层运动控制示例，完成趴下与站立测试。
- 使用 SDK 的 VUI 示例，完成灯光亮度控制测试。

## 阅读说明

- 文档中的 IP 地址、网卡名（例如 `ens33`）和磁盘路径对应当时的设备，并非所有机器通用。
- 区分“已经实测成功”和“仍待确认”的步骤，不把未完成的实验写成成功案例。
- 运行运动控制示例前，确保机器狗周围有安全空间，并有人现场看护。
- 仓库中的 `.gitignore` 是 Git 忽略规则配置文件，**不是调试教程**；具体操作请从上面的文档入口进入。
